# Track Workshop Outlines

Each workshop uses one shared case, one injected failure, one evidence review, and one changed constraint.

## Product / Operator

- user task and deterministic baseline
- bounded workflow, authority, handoff, and override
- task outcome, correction, latency/cost, accessibility, privacy
- current product claim audit
- deliverable: evaluated operating design

## Platform / SRE

- durable task/state model
- retry/idempotency/cancel/recovery
- SLO, correlated observability, capacity and cost
- incident, migration, backup, rollback
- deliverable: failure-tested deployment/runbook

## Security / Assurance

- identity/data/authority graph
- attack path and safe exploit
- layered controls, detection, recovery, variants
- NIST/OWASP control-evidence mapping
- deliverable: assurance report with residual risk

## Tools / Protocols

- tool/interface shape and least authority
- MCP/A2A lifecycle and identity
- errors, timeout, cancellation, compatibility
- malicious content and supply chain
- deliverable: independently tested extension/adapter

## Core / Framework

- source trace and invariant
- runtime/state/orchestration subsystem
- regression, performance, compatibility, migration
- upstream conventions and maintenance
- deliverable: scoped tested change or subsystem

## Local-Model Infrastructure

- hardware/workload/privacy requirements
- serving/routing architecture
- quality/latency/throughput/resource measurements
- failure, fallback, degradation, operations
- deliverable: measured recommendation and changed-constraint retest
