# Assessment Assets

## Purpose

Support valid, reliable, explainable decisions about learner capability. These assets must be adapted to local context and calibrated with common anchor work before high-stakes use.

## Assets

- [Question Bank](question-bank.md) - retrieval, explanation, analysis, and design prompts
- [Practical Exams](practical-exams.md) - controlled implementation and failure-recovery assessments
- [Oral Defense Bank](oral-defense-bank.md) - authenticity, tracing, judgment, and transfer probes
- [Assessor Calibration Guide](assessor-calibration-guide.md) - common scoring process
- [Grading Packet Templates](grading-packet-templates.md) - evidence recording
- [Answer-Key Guidance](answer-key-guidance.md) - how to build keys without freezing fast-moving facts
- [Feedback Bank](feedback-bank.md) - repair-oriented feedback patterns
- [Track Evaluation Sheets](track-evaluation-sheets.md) - specialization evidence

## Use Rules

- Select items from multiple competencies and evidence levels.
- Change surface details and constraints between practice and graded work.
- Use direct practical, trace, end-state, and oral evidence for high-stakes decisions.
- Do not reuse public task fixtures as hidden-transfer evidence.
- Disclose permitted agent/tool use and require designated independent segments.
- Treat critical security, fabricated evidence, and inability-to-explain failures as gates, not point deductions.
- Version product/framework questions and verify them before use.

## Minimum High-Stakes Evidence

A final decision combines:

- one unseen trace/debug task
- one implementation or operations practical
- one security or failure-injection task
- one evaluation-evidence task
- one oral defense
- one delayed changed-condition transfer task

No multiple-choice or written-explanation score alone can establish implementation, security, or production competency.
