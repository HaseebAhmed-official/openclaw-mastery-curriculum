# Capstones

## Purpose

Integrate the complete program in a working, bounded agent system that survives implementation review, repeated evaluation, authorized attack, incident recovery, oral defense, and changed-condition transfer.

## Core Rule

The capstone must solve a justified problem and include a deterministic baseline. More agents, tools, or framework features do not increase quality unless evidence shows they improve the target outcome enough to justify added uncertainty, cost, and risk.

## Required Gates

1. Problem and agentic-justification gate.
2. Architecture, data, authority, failure, and evidence-plan gate.
3. Working core and deterministic-test gate.
4. Security and evaluation gate.
5. Deployment, SLO, incident, privacy, and rollback gate.
6. Release-candidate red team.
7. Team board plus individual oral defense.
8. Delayed changed-condition transfer.
