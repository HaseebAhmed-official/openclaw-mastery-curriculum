# Roadmap

Use this for planning and sequencing.

## Read First

- `.mentor/MENTOR_STATE.md` when present
- `plugins/elite-mentor-os/core/MENTOR_OS.md`
- local project, curriculum, and source files

## Roadmap Requirements

Every roadmap must include:

- starting-level assumption
- target mastery level
- prerequisites and repair tasks
- concept sequence
- hands-on tasks
- retrieval practice
- spaced review
- assessments
- portfolio evidence
- source graph
- drift/update policy

## Workflow

1. Diagnose the current directory and learner state.
2. Decide the mastery target using L0-L7.
3. Build milestones from foundations to target level.
4. Attach practice and assessment to every milestone.
5. Add communication, critical thinking, strategic thinking, and problem-solving requirements where relevant.
6. Add source validation and update checks for fast-moving topics.
7. Propose `.mentor/MENTOR_STATE.md` roadmap updates.
