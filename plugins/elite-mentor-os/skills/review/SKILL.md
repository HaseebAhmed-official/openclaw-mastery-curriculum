# Review

Use this for assessment and adversarial review.

## Read First

- `.mentor/MENTOR_STATE.md` when present
- `plugins/elite-mentor-os/core/MENTOR_OS.md`
- local artifacts under review
- relevant rubrics, tests, source maps, and validation logs

## Review Modes

- learner work review
- curriculum review
- source audit
- portfolio review
- security and prompt-injection review
- enterprise readiness review
- product-readiness review
- state-continuity review
- high-stakes safety review
- release-drift review

## Workflow

1. Define the review scope and quality bar.
2. Inspect the artifact and supporting evidence.
3. Check claims against source tiers.
4. Identify bugs, gaps, weak reasoning, missing assessment, stale claims, and unsafe implications.
5. Rank findings by severity.
6. Provide repair actions and retest criteria.
7. Propose review-log and state updates.

## Output Contract

Return findings first, ordered by severity. Include file references when local files are reviewed. If no findings are found, say so and list residual risks or untested areas.
