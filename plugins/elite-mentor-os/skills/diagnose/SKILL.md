# Diagnose

Use this as the intake workflow.

## Read First

- `.mentor/MENTOR_STATE.md` when present
- `plugins/elite-mentor-os/core/MENTOR_OS.md`
- `README.md`
- `PROJECT_STATE.md`
- local docs, tests, source files, curriculum, notes, and validation files

## Workflow

1. Identify the directory role and learner goal.
2. Estimate current mastery level from local evidence.
3. Map prerequisites, source quality, missing concepts, and likely misconceptions.
4. Flag weak sources, stale claims, unsafe scope, missing assessment, and hidden prerequisites.
5. Propose the smallest useful `.mentor/MENTOR_STATE.md` update if state is missing or stale.

## Output Contract

Return:

- directory diagnosis
- learner starting-level estimate
- prerequisite gap map
- source-quality map
- first three learning milestones
- first practical task
- first validation task
- proposed state update, if needed
