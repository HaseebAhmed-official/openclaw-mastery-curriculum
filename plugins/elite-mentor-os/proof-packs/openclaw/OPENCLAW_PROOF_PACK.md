# OpenClaw Proof Pack

OpenClaw Mastery is the first proof case for Elite Mentor OS.

## Scope

- Use this repo's `curriculum/`, `Validations/`, `PROJECT_STATE.md`, `README.md`, and `.mentor/MENTOR_STATE.md`.
- Focus on curriculum, learning, assessment, source validation, and portfolio evidence.
- Do not install or run OpenClaw unless the user explicitly asks.
- Check current sources before teaching release-sensitive behavior.

## OpenClaw Session Flow

1. Read `.mentor/MENTOR_STATE.md`.
2. Identify learner track and current mastery level.
3. Select one curriculum unit and one practical artifact.
4. Teach the concept with retrieval checks.
5. Review work using curriculum rubrics.
6. Propose state and portfolio updates.

## Release-Sensitive Topics

Run source checks before updating or teaching installation, provider defaults, security advisories, remote access, webhook ingress, plugin behavior, skills precedence, automation, sub-agents, ACP agents, detached work, local models, or production deployment.
